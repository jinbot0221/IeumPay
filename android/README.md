# 이음페이 Android 태블릿 POS

Kotlin 네이티브 Activity 기반 개발용 앱입니다. Android 8.0(API 26) 이상. WebView로 웹사이트를 띄우는 앱이 아닙니다.

## Android Studio에서 빌드

1. `android` 폴더를 Android Studio에서 엽니다.
2. Android SDK Platform 35 및 Build Tools 35.0.0을 설치합니다. JDK 17 이상(이 환경은 21)을 사용합니다.
3. Gradle 동기화 후 `app`의 debug 변형을 실행합니다.
4. 백엔드: 상위 폴더에서 Node.js 24로 `npm start`.
5. 에뮬레이터의 앱 서버 주소는 `http://10.0.2.2:3000`입니다.
6. USB 실기기는 `adb reverse tcp:3000 tcp:3000` 후 앱 서버 주소를 `http://127.0.0.1:3000`으로 설정합니다. USB 연결은 서버 접근용이며 카드 리더 연동이 아닙니다.

이 클라우드의 빌드: `cd /workspace/IeumPay/android && python ../scripts/cloud-android-build.py :app:assembleDebug`.
결과: `app/build/outputs/apk/debug/app-debug.apk`.
Android Studio에서는 SDK 경로가 다른 `local.properties`를 현지 환경에 맞게 생성하세요. 이 파일은 Git에서 제외됩니다.

## 기획서 v1.5 대비 구현 범위

| 화면 | 현재 동작 | 실제 서비스 전 필요한 작업 |
|---|---|---|
| T01 등록 | 서버 health 확인, 데모 매장 연결 | 일회용 등록코드·단말 자격·서버 배정 |
| T02 로그인 | 비밀번호 없는 명시적 데모 진입 | 직원 인증·잠금·권한·세션 |
| T03 홈 | 서버 테스트 거래 합계·지갑 | 한국시간 오늘 집계·가맹점 범위 |
| T04 주문 | 샘플 상품 수량·직접 금액·범위 검사 | 서버 상품 가격·주문 생성·사유 |
| T05 수단 | 테스트 코인 결제, 외부 수단 비활성 | VAN SDK·지원 수단 설정 |
| T06 대기 | 요청 키 로컬 저장, 응답 유실 시 동일 키 복구 | 주문 QR·고객 별도 인증·만료·상태조회 API |
| T07 결과 | 서버 응답 금액·유료/혜택 차감 명세 | 실제 영수증·출력 |
| T08 내역 | 서버 거래 조회 | 기간·필터·페이지·가맹점 격리 |
| T09 취소 | 사유 필수, 서버 전체 복원 | 취소 권한·재인증·외부 승인 확인 |
| T10 장비 | 기종·OS·앱·통신 확인 | 리더 펌웨어·등록 ID·관제·차단 |

데모 서버는 단일 공유 테스트 지갑입니다. 코인 결제는 혜택 먼저 차감하고 유료 잔액을 사용합니다. 취소 시 원래 사용한 두 재원을 복원합니다. 아직 지급분별 만료·사용처 정책·복식원장·실제 충전·환급을 구현하지 않았습니다. 고객·관리자·온라인 결제 화면 C/M/A/O의 전체 구현은 이번 태블릿 앱 범위에 포함되지 않습니다.

## 안전한 테스트

- 실제 금전, 개인정보, 카드정보를 입력하지 마세요. 공개 서비스에 배포하지 마세요.
- HTTP 연결은 debug에만 허용됩니다. 실제 서비스는 HTTPS·인증·단말 키 보관·서버 범위 검사가 필요합니다.
- 등록 정보와 미확정 결제 요청(금액·요청 ID)은 앱 전용 SharedPreferences에 보관됩니다. 인증정보는 저장하지 않습니다. 백업은 비활성입니다.
- 결제 응답 유실 시 새 요청 키를 만들지 않습니다. 앱 재시작 → 데모 진입 → 기존 요청 확인으로 복구합니다. 확정 400 거절(예: 잔액 부족)은 결제수단 화면으로 돌아갑니다. 5xx·통신 오류는 결과 확인 상태를 유지합니다.
- 미확정 거래가 있는 동안 서버 주소를 변경하거나 앱 데이터를 삭제하지 마세요. 서버 DB도 보존하세요.
- 카드·Apple Pay·삼성페이·카카오페이·네이버페이는 미연동으로 비활성화했습니다. 외부 결제가 성공했다고 표시하지 않습니다.
- 실기기 화면·가로/세로·앱 종료 복구·네트워크 단절·VAN 장비 검수는 별도로 수행해야 합니다.

검증: debug APK 빌드·서명 검증 완료. 백엔드 테스트 5개 통과(서버 재시작 후 동일 요청 복구 포함). 실기기·에뮬레이터 UI 실행 검증은 아직 수행하지 않았습니다.
Android Lint: 0 errors / 3 warnings (동기 SharedPreferences 저장 권고 2건, 구형 Android 백업 설정 권고 1건). 미확정 결제 참조는 전송 전에 동기 저장하며 Android 12+ 백업·기기 이전 제외 규칙을 적용했습니다.
